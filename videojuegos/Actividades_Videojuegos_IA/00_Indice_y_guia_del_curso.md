# Curso: Desarrollo de Videojuegos con IA — Índice general

**Duración total:** 16 clases de 50 minutos · **Modalidad:** individual · **Entrega:** repositorio GitHub público por estudiante

## Cómo se usa este curso

Cada actividad es una clase completa de 50 minutos. La consigna es siempre la misma en su esencia:

1. Leer el **marco teórico** (10 min).
2. Seguir el **paso a paso** e implementar el juego (30 min).
3. Usar la **IA** como asistente de código y de ideas (integrado en el paso 2).
4. **Publicar** el avance en el repositorio GitHub personal (10 min).

Cada estudiante crea **un solo repositorio público** (por ejemplo `mis-videojuegos`) y guarda cada clase en una carpeta (por ejemplo `clase_01_nibbles/`). Así queda el progreso acumulado, visible y en versiones.

## Herramientas de IA sugeridas

- ChatGPT, Gemini, Claude, Copilot o cualquier asistente de código.
- Regla de oro: la IA **ayuda**, pero el que piensa, decide y escribe la lógica es el estudiante. Nunca copiar y pegar código sin entenderlo.
- Cada actividad trae "prompts" listos para copiar y adaptar.

## Plan de 16 actividades

|----|-------|------------------------|-------|

| 03 | Física y tiro parabólico | Cañones | Python + Pygame |

## Tipos de juegos que se ven

Arcade (Snake, Arkanoid, Invaders), física/simulación (Cañones), plataformas (El Mono), aventura gráfica, web, turnos (Batalla naval), multijugador en red, trivia, memoria, laberinto/puzle y un motor profesional open source (Godot).

## Repositorio GitHub sugerido

1. Crear cuenta en https://github.com
2. Crear repo público `mis-videojuegos` (con README).
3. En cada clase: `git add .` + `git commit -m "Clase 01: ..."` + `git push`.
4. Compartir el link del repo en la entrega.
